# 02. UI/UX 디자인 지침

## 1. 시각적 방향
첨부된 참고 화면은 검정에 가까운 배경 위에 노랑·보라·핑크의 커다란 둥근 패널을 쌓고, 손으로 그린 듯한 굵은 글자와 귀여운 장식 캐릭터를 사용하는 장난스럽고 밝은 스타일이다. 이 프로젝트는 이 분위기와 색상 조합을 참고하되 원본의 브랜드명·로고·캐릭터·서체를 복제하지 않는다.

### 디자인 토큰(초기 제안)
- 배경: `#090909` 또는 `#101010`
- 기본 글자: `#111111`(밝은 패널 위), `#F7F4EC`(어두운 배경 위)
- 노랑: `#F4E95A`
- 보라: `#8B63EE`
- 핑크: `#F093B0`
- 카드 보조색: `#FFF7E8`
- 오류: 충분한 대비를 가진 붉은 계열 + 오류 텍스트
- 모서리: 큰 패널 28~40px, 카드 18~24px, 버튼 pill 형태
- 그림자: 과도한 입체감보다 부드럽고 얕은 그림자
- 글꼴: 한글 가독성이 좋은 무료 웹폰트 또는 시스템 폰트. 장식용 글꼴은 큰 제목에 제한적으로 사용하고 본문은 읽기 쉬운 글꼴 사용.

색상과 크기는 CSS 변수로 관리한다. 작은 본문을 손글씨체로 설정하지 않는다.

## 2. 화면 구성
### 상단 헤더
- 서비스명(가칭)과 간단한 설명.
- 우측에 데이터 상태/샘플 모드 표시.
- 장식용 아이콘은 보조 역할만 수행.

### 검색 패널(노란색)
- 큰 둥근 노란 패널.
- 제목 예: `오늘 말고, 라운딩할 날을 골라봐요!`
- 날짜 선택 필드.
- 출발 위치 입력 필드(선택 사항)와 위치 권한 버튼.
- 검색 버튼.
- 필수 날짜와 선택 위치를 시각적으로 구분.

### 추천 패널(보라색)
- 검색 후 추천 골프장 최대 3개를 큰 보라색 영역 안에 카드 또는 가로 스크롤로 표시.
- 각 추천의 순위, 골프장명, 거리(계산 가능한 경우), 추천 이유를 표시.
- 거리 미적용이면 `출발 위치 미입력 — 거리 제외`를 표시.
- 추천 사유는 짧고 구체적으로 작성.

### 전체 골프장 결과(핑크/밝은 카드)
- 골프장 카드에 이름, 주소, 가격, 티타임, 예약 상태, 날씨, 강수확률, 확인 시각을 표시.
- 카드가 길어지면 정보 그룹을 나누고 모바일에서 세로로 배치.
- 예약하기 버튼은 시각적으로 보이되 실제 예약이 되지 않는다는 안내를 바로 확인할 수 있어야 한다.
- 참고 화면의 물방울/드립 형태는 섹션 하단의 장식으로만 사용하고 정보 가독성을 침해하지 않는다.

## 3. 반응형 기준
- 모바일(기준 360px): 한 열 레이아웃, 검색 폼 세로 정렬, 카드 정보 2열 또는 1열.
- 태블릿: 추천 카드 2열, 결과 카드 1~2열.
- 데스크톱: 콘텐츠 최대 너비를 제한하고 추천 3개를 나란히 배치할 수 있다.
- 가로 스크롤은 추천 카드처럼 의도된 영역에서만 허용한다.
- 뷰포트 320px에서도 주요 버튼과 정보가 잘리지 않아야 한다.

## 4. 상태별 UI
- 초기: 날짜 선택 안내와 검색 유도.
- 로딩: 버튼 로딩 상태와 스켈레톤 또는 진행 안내.
- 결과 있음: 검색 날짜, 결과 개수, 추천 3개 이하, 전체 결과.
- 결과 없음: `선택한 날짜에 표시할 골프장 정보가 없습니다.`와 날짜 변경 유도.
- 부분 실패: 실패한 정보 영역에만 `날씨 정보를 불러오지 못했습니다` 등 구체적 안내.
- 전체 실패: 재시도 버튼과 사용자 친화적 메시지.
- 예약 버튼: 클릭 시 명확한 안내 모달/인라인 알림. 예약 완료처럼 보이는 성공 토스트 금지.

## 5. 인터랙션 및 접근성
- 모든 입력은 label과 연결한다.
- 오류 메시지는 해당 입력 또는 결과 영역에 연결하고 `aria-live="polite"`를 적절히 사용한다.
- 모달 사용 시 포커스 이동·닫기·Esc 동작을 구현한다. 간단한 안내라면 인라인 알림을 우선한다.
- 버튼은 키보드로 조작 가능하고 포커스 테두리를 숨기지 않는다.
- 상태를 색상만으로 표현하지 않는다.
- 애니메이션은 짧고 절제하며 `prefers-reduced-motion`을 지원한다.
- 장식용 캐릭터·도형은 대체 텍스트가 불필요하면 스크린리더에서 숨긴다.

## 6. UI 완료 기준
- 참고 이미지와 같은 어두운 바탕 + 노랑/보라/핑크의 큰 둥근 패널 분위기가 드러난다.
- 실제 서비스의 정보 우선순위가 장식보다 높다.
- 날짜 선택, 출발 위치, 검색, 추천, 결과 카드, 예약 미지원 안내가 모두 보인다.
- 360px 및 1280px 화면에서 레이아웃 검증을 통과한다.
